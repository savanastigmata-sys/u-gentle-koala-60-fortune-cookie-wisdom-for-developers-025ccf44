One original line of fortune-cookie wisdom for a software developer, 94 characters: "The fortune you seek is not in the cookie, but in the stack trace you finally learned to read." The fortune is not in the cookie at all — it is in the stack trace the developer finally learned to read.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `./output/entry.txt`). It is deterministic: the same line, byte for byte, on every run. It validates the line first — one line, 1–120 characters, valid UTF-8.
